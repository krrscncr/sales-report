# Sales Report

Учебный проект: анализ продаж из CSV-файла и из базы данных MySQL.
В обеих версиях считается выручка по дням, товарам и категориям, 
строится топ-5 товаров и сохраняется отчёт в Excel.

## Две версии

### csv_version
Читает данные из `data/sales.csv`. Проще в запуске — не нужна база данных.
Подходит для быстрого старта.

### db_version
Читает данные из MySQL. Показывает, как работать с реальной базой данных 
через SQLAlchemy.

## Технологии
- Python 3.12
- pandas, openpyxl
- SQLAlchemy, mysql-connector-python (для db_version)

## Что общего
Логика обработки данных в обеих версиях идентична. Меняется только 
источник данных — файл или база. Это демонстрирует, что код обработки 
не зависит от источника.
